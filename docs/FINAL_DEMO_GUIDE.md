# 보안 Agent 「빈」 완성본 시연·정리 (학생 작성 · 권빈)

마지막 총공세 7일차 정리 문서입니다. 22단계까지 만든 보안 Agent 앱 「빈」을 내 PC에서 쓰는 앱으로 마무리한 결과를 시연 순서·기능 구분·한계·확인 근거로 나눠 적었습니다. **확인하지 않은 것은 '된다'고 쓰지 않았습니다.**

- 저장소: https://github.com/kwonbhin/choi-bujang-secret-vault
- 앱 폴더: `on-client` (시작 틀 0.2.19)
- 작전: 화면 틀 **관제 대시보드형**(맨 위 상태 카드 → 아래 추이·기록), 포장 형태 **포장 없이 프로젝트 폴더에서 실행**(`npm run package-app` 실행하지 않음)

> **확인 수준 표기** — [실제 확인]: Windows PC에서 직접 실행·화면으로 본 것 / [예제·모의 확인]: Linux 예제(--demo)나 가짜 입력으로 학생 함수만 실행해 본 것 / [포털 판정]: ALEPH 판정 환경이 커밋 코드를 읽어 통과시킨 것 / [미확인]: 확인하지 못한 것

## 2. 핵심 기능 3가지 — 시연 순서

실행은 7장을 먼저 봅니다. 앱을 켜고 `http://127.0.0.1:5189/` 를 연 상태에서 시작합니다.

### 시연 1 — 내 PC 점검 (내가 만든 대시보드)
1. 「보호 현황」 메뉴를 엽니다. 핵심(학생) 카드가 앞에 오도록 배치돼 있습니다(`appearance.json` student-first).
2. 「내 PC 점검」의 **「내 PC 다시 조회」** 버튼을 누릅니다.
3. 상태 카드(CPU·메모리·디스크·네트워크 구성·방화벽·Windows기록)와 요약 한 줄을 봅니다. **읽은 값은 '측정값', 못 읽은 값은 '확인 불가'+이유**로 나옵니다.
4. 버튼을 **한 번 더** 눌러 **「직전 조회 대비 추이」**(▲/▼/= %p)를 봅니다.
5. 「근거와 한계 보기」를 펼쳐 "이 건수는 침해·공격 탐지 결과가 아님" 등 한계를 확인합니다.
   - 맨 위 **"SDP(접근제어) 서버: …"** 줄은 이 로컬 조회가 SDP 서버 연결과 **별개**임을 보여 줍니다.

### 시연 2 — 업무 앱 접근 판정 (`renderDecision`, 14단계)
1. 「업무 앱」 메뉴에서 앱 하나를 고릅니다.
2. 판정 결과가 **허용·거부·추가 확인 필요·확인 불가**로 서로 다르게 보이고, **요청 자체가 실패한 경우도 따로** 보입니다.
3. 각 결과의 **「다음에 할 일」** 한 줄을 확인합니다.

### 시연 3 — 보안 기록 + AI 설명 (`renderEvents`·`renderExplanation`, 15·18단계)
1. 「보안 기록」 메뉴에서 접속 기록·XDR 경보 목록을 봅니다(최신순·걸러 보기).
2. 한 줄을 눌러 상세(근거·규칙·상태)를 봅니다.
3. AI 설명을 요청하면, 설명이 **기록의 근거와 대조**되어 보입니다(근거 없으면 지어내지 않음).

## 3. 아직 안 되거나 '확인 불가'로 남은 한계 (정직하게)

- **실제 서버(엔진) 연결 안 됨**: 기본 실행은 "연결 없음(disconnected)". 사용자·기기·판정·기록의 실데이터는 접근제어 서버 + 어댑터 + 담당자 발급 개인 인증서가 있어야 열립니다(이번 과정 미발급). → 화면은 예제(demo)/미연결로 표시. [실제 확인: 미연결 표시]
- **방화벽·Windows 기록 실측**: Windows에서만 읽힙니다. 다른 OS에선 '확인 불가'(정상). 완성본 대시보드의 Windows 실측값은 **학생 PC에서 아직 확인하지 못함**. [미확인]
- **AI 사건 설명(18단계) 실제 실행**: 연결 점검은 verified 되었으나, 설명할 보안 기록이 없어 실제 설명 실행은 확인 못 함. [미확인]
- **조치 실제 처리(19단계)**: 원천 서버 조치 연결 미지원 → "지원 안 함"으로 표시. [코드 확인]
- **취약점 조회(20단계)**: 기본 실행엔 `ON_PROJECT_DIRECTORY`가 없어 `not_configured`로 보일 것으로 추정. 화면 실측 미확인. [코드 확인/미확인]
- '확인 불가'는 정상·안전이 아니라 "읽지 못함"을 뜻하며, 앱은 이를 정상처럼 바꾸지 않습니다.

## 5. 재현용 실행·확인 순서

```powershell
git clone https://github.com/kwonbhin/choi-bujang-secret-vault   # 처음 받는 경우
cd choi-bujang-secret-vault\on-client
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```
(Mac: `cd choi-bujang-secret-vault/on-client` → `npm start`. 예제는 `-Demo` / `npm run demo`)

1. 브라우저 `http://127.0.0.1:5189/` → 앱 이름 「빈」 확인
2. 시연 1 → 2 → 3 순서로 진행(2장)
3. 막히면 `docs/FINAL_RUN_GUIDE.md`의 「막힐 때」 표 참고
